Cursor Marketplace: oficiální rozšíření Claude Code trojanizováno perzistentním SSH backdoorem

The Hacker News · AI/agent · identity · cloud/AI-stack · malware-control · ai-dev-hooks

Výzkumníci v oblasti kybernetické bezpečnosti zveřejnili, že trojanizovaná verze oficiálního rozšíření Claude Code od společnosti Anthropic byla šířena přes Cursor Marketplace jako legitimní aktualizace a pokoušela se na zasažené systémy nainstalovat perzistentní SSH backdoor.

MITRE ATT&CK®

  • T1195.002 Compromise Software Supply Chain„distributed through the Cursor Marketplace as a legitimate update“
  • T1176.002 IDE Extensions„trojanized version of Anthropic's official Claude Code extension“

Techniku přiřadil model z uzavřeného slovníku ATT&CK v20; citace je z našeho výtahu zprávy, ne z celého článku. Metodu ověřil druhý posuzovatel naslepo 22/27 (28. 10. 2026) na jiném vzorku — toto přiřazení druhý posuzovatel neviděl. Přiřazení dělá TIA; MITRE ho nevytváří ani neschvaluje.
